Constructor for a new Nonlinear 3D solid-shell MRESS object. This constructor can be used for the stiffness matrix.

Parameters
path_inString with the full path to the license file.
xyz_inNodal coordinates of the eight 3D solid-shell element nodes, stored in xyz_in[0:7][0:2], where each row corresponds to a node of the element and each column corresponds to the x,y, and z coordinates.
stresses_inThe stresses at the integration points must be provided as input to the class constructor. These stresses are required for the computation of the internal force vector and the initial stress stiffness matrix.
The stress input format is defined as follows:
Sxx, Syy, Szz, Sxy, Sxz, Syz, i.e., six stress components per integration point along the thickness direction. The stresses are stored in the "stresses_" vector, ordered by integration points through the thickness in a bottom-to-top direction, from zet = -1.0 to zet = +1.0.
For example, with two integration points through the thickness, zet1 = -1.0 / sqrt(3.0) and zet2 = +1.0 / sqrt(3.0), the ordering in stresses_ is:
[Sxx^zet1, Syy^zet1, Szz^zet1, Sxy^zet1, Sxz^zet1, Syz^zet1, Sxx^zet2, Syy^zet2, Szz^zet2, Sxy^zet2, Sxz^zet2, Syz^zet2]
DMatrix_inFull 3D constitutive matrix, stored in vector form with size = 36. The "DMatrix_in" vector must contain the 6x6 full 3D constitutive matrix for all integration points along the thickness direction of the shell element. The procedure to construct this vector is the following:
  1. Loop in the integration points along thickness direction: for (int izet = 0; izet < zetGPCoord_in.size(); ++izet) {
  2. Insert the 6x6 D-matrix, stored in vector form ("DMatrix[0:35]"), into the "DMatrix_in" vector:
    2.1 for (int i = 0; i < 36; ++i) { DMatrix_in.push_back(DMatrix[i]); }
Young_inYoung's modulus of the material.
Poisson_inPoisson's ratio of the material.
zetGPcoord_inNatural coordinates of the Gauss integration points along the thickness direction of the element. The number of integration points along the thickness direction is defined thereafter through the size of this vector.
zetGPweight_inWeights of the Gauss integration points along the thickness direction of the element. The size of this vector must be the same as the size of "zetGPcoord_in".

Constructor for a new Nonlinear 3D solid-shell MRESS object to be used with composite materials. This constructor can be used for the stiffness matrix of the composite laminate.

Parameters
path_inString with the full path to the license file.
xyz_inNodal coordinates of the eight 3D solid-shell element nodes, stored in xyz_in[0:7][0:2], where each row corresponds to a node of the element and each column corresponds to the x,y, and z coordinates.
stresses_inThe stresses at each ply must be provided as input to the class constructor if the calculation of internal forces or the geometric stiffness matrix are required. If this constructor is called only for the linear stiffness matrix then the "stresses_in" vector can be passed in as empty. The stress input format is defined as follows:
Sxx, Syy, Szz, Sxy, Sxz, Syz, i.e., six stress components per ply of the laminate. The stresses are stored in the "stresses_" vector, ordered by integration points through the thickness in a bottom-to-top direction, from zet = -1.0 to zet = +1.0. Please note that for composites each integration point along thickness is associated to a ply.
For example, with two plies through the thickness, zet1 = -1.0 / sqrt(3.0) and zet2 = +1.0 / sqrt(3.0), the ordering in stresses_ is:
[Sxx^zet1, Syy^zet1, Szz^zet1, Sxy^zet1, Sxz^zet1, Syz^zet1, Sxx^zet2, Syy^zet2, Szz^zet2, Sxy^zet2, Sxz^zet2, Syz^zet2]
DMatrix_inFull 3D constitutive matrix for composites ([D]=transpose([C])*[Q]*[C]), stored in vector form with size = 36. [Q]={[Q11 Q12 Q13 0 0 0] [Q21 Q22 Q23 0 0 0] [Q31 Q32 Q33 0 0 0] [0 0 0 Q44 0 0] [0 0 0 0 Q55 0] [0 0 0 0 0 Q66]} is known as the stiffness of the lamina or ply and [C] is the transformation matrix for the stresses from the global into the local lamina coordinate system. The components of [Q] are :
Q11 = E_x/(1.0-pois_xy*pois_yx);
Q22 = E_y/(1.0-pois_xy*pois_yx);
Q33 = Q22;
Q12 = E_x*pois_yx/(1.0-pois_xy*pois_yx);
Q13 = Q12;
Q21 = E_y*pois_xy/(1.0-pois_xy*pois_yx);
Q23 = Q21;
Q31 = Q21;
Q32 = Q31;
Q44 = g_xy;
Q55 = (5.0*E_x)*(1.0/(12.0*(1.0+pois_xy)));
Q66 = Q55;
[Q] is organised in vector form as follows:
[Q][0] = Q11;
[Q][1] = Q12;
[Q][2] = Q13;
[Q][6] = Q21;
[Q][7] = Q22;
[Q][8] = Q23;
[Q][12] = Q31;
[Q][13] = Q32;
[Q][14] = Q33;
[Q][21] = Q44;
[Q][28] = Q55;
[Q][35] = Q66;
The transformation matrix [C] should be defined as follows:
lx = c;
mx = s;
nx = 0.0;
ly = -s;
my = c;
ny = 0.0;
lz = 0.0;
mz = 0.0;
nz = 1.0;
[C][0] = lx*lx;
[C][1] = mx*mx;
[C][2] = nx*nx;
[C][3] = lx*mx;
[C][4] = lx*nx;
[C][5] = mx*nx;
[C][6+0] = ly*ly;
[C][6+1] = my*my;
[C][6+2] = ny*ny;
[C][6+3] = ly*my;
[C][6+4] = ly*ny;
[C][6+5] = my*ny;
[C][12+0] = lz*lz;
[C][12+1] = mz*mz;
[C][12+2] = nz*nz;
[C][12+3] = lz*mz;
[C][12+4] = lz*nz;
[C][12+5] = mz*nz;
[C][18+0] = 2.0*lx*ly;
[C][18+1] = 2.0*mx*my;
[C][18+2] = 2.0*nx*ny;
[C][18+3] = lx*my+ly*mx;
[C][18+4] = lx*ny+ly*nx;
[C][18+5] = mx*ny+my*nx;
[C][24+0] = 2.0*lx*lz;
[C][24+1] = 2.0*mx*mz;
[C][24+2] = 2.0*nx*nz;
[C][24+3] = lx*mz+lz*mx;
[C][24+4] = lx*nz+lz*nx;
[C][24+5] = mx*nz+mz*nx;
[C][30+0] = 2.0*ly*lz;
[C][30+1] = 2.0*my*mz;
[C][30+2] = 2.0*ny*nz;
[C][30+3] = ly*mz+lz*my;
[C][30+4] = ly*nz+lz*ny;
[C][30+5] = my*nz+mz*ny;
[D]=transpose([C])*[Q]*[C]

  1. Loop in the integration points along thickness direction: for (int izet = 0; izet < zetGPCoord_in.size(); ++izet) {
  2. Insert the 6x6 [D]-matrix, stored in vector form ("[D][0:35]"), into the "DMatrix_in" vector:
    2.1 for (int i = 0; i < 36; ++i) { DMatrix_in.push_back([D][i]); }
Young_inYoung's modulus of the material.
Poisson_inPoisson's ratio of the material.
zetGPcoord_inNatural coordinates of the Gauss integration points along the thickness direction of the element. For composites there is a slight variation on how this vector is defined because the zet-coordinate for each ply should be located at the midpoint of the ply and the associated weight, when multiplied by the determinant of the Jacobian, must reflect the thickness of the ply. The number of integration points along the thickness direction is equal to the number of plies on the laminate.
zetGPweight_inWeights of the Gauss integration points along the thickness direction of the element. As said in "zetGPcoord_in", the weight of the integration point must reflect the ply thickness when multiplied by the determinant of the Jacobian. The size of this vector must be the same as the size of "zetGPcoord_in".
ply_centre_coord_parametric_inParametric zet-coordinate of the centre of the ply along the thickness direction.
ply_thickness_parametric_inVector with the thickness of each ply in the laminate.

Calculates and gets the linear stiffness matrix "Stiffness_" of the MRESS element for composite materials. It includes the hourglass stabilization matrix.

Returns
vector<double> The return is the stiffness matrix "Stiffness_" in vector form (of size = 576). The first elements in the output vector (Stiffness_[0:23]) correspond to the first 24 elements in the first row of the 24 x 24 stiffness
(stif[0][0:23]), the next 24 elements in the output vector (Stiffness_[24:47]) correspond to stif[1][0:23], and so on.
